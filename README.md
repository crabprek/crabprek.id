# 🚀 Personal Portfolio Website

Website portofolio pribadi yang modern, sinematik, dan responsif. Dibuat menggunakan murni **HTML5, CSS3, dan Vanilla JavaScript** tanpa ketergantungan framework (*zero dependencies*), memiliki waktu muat super cepat, serta siap di-deploy langsung melalui **GitHub Pages**.

---

## 🛠️ Fitur Utama

- ⚡ **Ultra-Fast Performance**: Ringan, tanpa library eksternal yang membebani browser.
- 🎨 **Modern Dark-Mode Aesthetics**: Tampilan obsidian dengan aksen gradien dan *glassmorphic navbar*.
- 📱 **Fully Responsive Layout**: Tampilan menyesuaikan secara sempurna di desktop, tablet, dan smartphone.
- ✨ **Interactive Scroll Reveal**: Transisi antar seksi yang halus saat di-scroll.
- 🛠️ **Developer Friendly**: Siap dijalankan langsung melalui **VS Code** dan **Git**.
